# TripCraft symbol assets

The transparent PNG symbols were recreated from the supplied orange sun/wave logo reference using the built-in ImageGen tool, then optimized to 256 × 256 PNGs for interface use.

- `tripcraft-symbol.png`: orange sun with a navy wave for light surfaces.
- `tripcraft-symbol-dark.png`: the same emblem with an ivory wave for dark surfaces.

Generation direction: reproduce only the travel emblem from the reference, preserve its sun/wave geometry, omit all lettering and background, use a transparent square canvas with small margins. The dark variant changes the navy wave to warm ivory while retaining the orange sun and transparency.

The `Brand` component renders the name as real HTML text. These are reference-based recreations, not original vector brand masters.
